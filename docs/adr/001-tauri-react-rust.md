# ADR-001: Tauri, React и Rust

- Статус: accepted
- Дата: 2026-09-29

## Контекст

Приложение должно постоянно работать в фоне на macOS и Linux, показывать окна и системные уведомления, хранить данные локально и потреблять меньше ресурсов, чем типичное Electron-приложение.

## Решение

Использовать Tauri 2 как desktop runtime, React + TypeScript + Vite для интерфейса и Rust для фоновой логики и системной интеграции.

## Последствия

- Один frontend используется на обеих платформах.
- Планировщик не зависит от жизненного цикла webview.
- Команда должна поддерживать два toolchain: Node.js и Rust.
- Платформенные особенности tray, уведомлений и упаковки всё равно требуют отдельных проверок.
