# ADR-002: SQLite принадлежит Rust-слою

- Статус: accepted
- Дата: 2026-09-29

## Контекст

К базе обращаются как пользовательский интерфейс, так и фоновый планировщик. Прямой SQL из frontend создаст два места для бизнес-правил и усложнит атомарное завершение тренировки.

## Решение

Соединение SQLite, миграции и транзакции находятся в Rust-слое. Frontend получает данные и выполняет операции только через типизированные Tauri commands.

## Последствия

- Инварианты планировщика и хранилища реализуются в одном месте.
- Tauri capabilities можно держать минимальными.
- Для DTO нужен явный контракт Rust ↔ TypeScript.
- Изменения схемы сопровождаются миграцией и интеграционными тестами.
